The final validator uses OLD pending snapshot retained only in the transaction queue; it is not persisted after cleanup. Forcing SET CONSTRAINTS ALL IMMEDIATE must not disable the ordinary affected-writer seals. Later independent transactions and unrelated users/units remain available. Source SQL must enumerate exact relation/op and OLD/NEW matching, private EXECUTE revocation and search_path. UTC serialization is confined to pure typed-row conversion; no caller date/authority timezone is changed.

Required private source hashes are not substitutes for live native validation. Native full preflight and confirmation repeat the same private prepareRewardDecisionTx prefix, including native RLS-visible governance/award calculations and required seats. The separate opaque whole-effect snapshot covers consistency and unrelated effects without exposing restricted GR data. Stable native IDs/timestamps/physical versions enter private proof; no preview ID/time is manufactured. Human reason >=10 is a deliberate bounded Assistant input rule; native default/short-reason behavior stays unchanged and must retain legacy regression coverage.
