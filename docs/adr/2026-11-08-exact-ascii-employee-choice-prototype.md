## Input-free experimental runtime owner

The reader calls one private qualification owner. It accepts no versions,
eligible boolean, GUC, environment authorization flag, injected process object,
JSON receipt or caller-created token. Protected reviewed source and the hosted
controller bind its bytes; the runtime report itself is not trusted authority.

On first relevant nonempty ASCII lookup, the owner captures actual process
identity, versions and the actual string intrinsics. It opens the fixed Linux
/proc/self/exe, verifies the actual executable FD is a regular file and matches
process.execPath's device/inode, streams its exact bytes through a bounded64KiB
hash buffer with a256MiB ceiling, checks stable before/after metadata and the
qualified size/hash. It retains the actual FD identity for cheap drift checks;
it never rehashes124MiB per lookup. Unknown platform/binary/source/mode refuses
the optimization and retains the original reader; ordinary lookup is not
poisoned. The owned FD closes on explicit experimental owner shutdown.

The owner examines bounded actual startup environment/argv from fixed proc
paths as well as current process state. Secret values are neither emitted nor
retained in reports. It rejects ICU data overrides (NODE_ICU_DATA, ICU_DATA,
--icu-data-dir), LD/DYLD loader overrides, NODE_PATH and unknown NODE_OPTIONS,
--import/--require/-r/--loader/--experimental-loader paths. No caller's deletion
of a current environment value can hide an inherited startup override.

There is one narrowly reviewed test-launch exception, NOT a production profile:
locked Vitest4.1.8 installs its own suppress-warnings.cjs with --require, plus
--experimental-import-meta-resolve. The actual package/version/path and full
source bytes must match the locked dependency, including suppress-warnings SHA
 a5012da3d2027007781baecda154d343d8c7ad2327b79bec65b1b60a41f42dd1.
That exact22-line/862-byte owner changes process.emit warning handling, not casing. Any
other preload/loader or unsupported flag falls back. Known fixed hosted heap
options may be classified explicitly; their acceptance cannot change the actual
resource grant. Root must review the final closed parser and actual captured
launch facts. A filename, suffix, candidate environment claim or arbitrary
node_modules require is insufficient. Unknown launch proof cannot qualify.

Binary/version alone is insufficient to assume the loaded ICU data. Initial
qualification therefore also executes the existing independent Unicode17
ASCII-observation derivation across EVERY valid scalar and the qualified85
context vectors, and requires the exact already-qualified fingerprint and
context expectations. It records initialization wall time/bytes separately.
All input/dependency source hashes and captured intrinsics must remain stable.
Each use cheaply rechecks process/version/FD/argv/current relevant environment
and intrinsic identity; any mismatch permanently disables the optimization for
that owner. This is semantic process qualification, never permission caching.

The current customer service unsets NODE_OPTIONS but does not exclude
NODE_ICU_DATA; protected worker examples likewise do not prove this production
profile. No service, startup environment or deployment file is changed here.
Production adoption requires separately protected startup/source/ICU closure.

the original native-purpose SQL and original JS fallback reader byte-for-byte.

principal owner; no new authorization policy or fake Tx is permitted. Any shared

no frozen historical baseline is silently edited for convenience.
