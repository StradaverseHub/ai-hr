# Explicit historical income-tax basis corrections

Approved feedback929ea296 introduces a separate append-only tax-input owner. Original payslip cash, statutory deductions, closed batch totals, import snapshots, issued documents and prior filing artifacts remain with their existing immutable owners. A correction supplies only the effective income-tax remuneration, per-code exemption use and classification-dependent relief inputs to future calculations and newly generated supported reports.

The country pack deterministically reconstructs saved cash lines and reconciles them to original gross and other deductions. Imported sources use the retained upload hash and immutable plan row bindings; ordinary sources need complete saved item contributions. Missing item identity, archived/ambiguous mappings, unsupported noncash/LP provenance and unavailable assessment-year rules refuse the whole employee. Cap-dependent replay requires original, year-bound TP3 opening-exemption evidence, including a saved zero; today's cleared TP3 does not establish historical zero. Plain uncapped classification changes do not read current TP3 balances.

Reviewed settings retain exact item IDs and flags in appliedSettings. Each correction also retains relevant year-rule version, source, signing/pack reference and exemption tables in rulesEvidence. Hashes bind the complete reviewed configuration and source. Replaced/reverted source revisions cannot inherit an overlay silently; a fresh exact-source correction explicitly supersedes only the same payslip or its immutable import-record lineage.

Payroll tax inputs cross the existing history barrier. Each employee's full selected period, correction rows and audit event commit atomically. A durable batch processes at most50 employees and40 seconds per authorized continuation. Review previews cache each retained import source once, permit at most1000 employees and refuse a preview exceeding25 seconds rather than return partial calculations. No recovery bypasses revoked authority.

New permissions distinguish tax-basis viewing from recalculation, using existing configurable per-company/tenant permission-set semantics. Service callers must preserve narrowed grant carriers and current company authority. SQL policies independently protect administrative previews, logs and writes. Corrected input rows remain readable to a caller permitted to read the original payslip, so withholding administrative-log access cannot silently cause a payroll/report consumer to ignore corrected tax data. Own-report readership exposes no other employee's correction history.

Existing annual report routing completeness remains mandatory. Display-only imported item lines never become EA-routing evidence. New EA/CP8D outputs without the required original routing provenance refuse rather than invent a statutory classification. Existing report/document bytes remain unchanged. Same-month PCB corrections use separate tax-only normal/additional inputs; EPF/SOCSO/EIS and original agency wages retain their original inputs.
