THE SITUATION TODAY

In Admin > Organisation, every company has a View and an Edit button, but both open the same editable page. Someone who only wants to check a company's details lands in a form where one stray change and a Save alters the company record, and the View button adds nothing.

WHAT WE'LL CHANGE

- View opens a new read-only page for the company. Everything is shown as plain text, under the same three tabs: General (logo, company information, contact details, default payroll cycle, parent company), Bank Account and Statutory.

- The read-only page has no boxes to type into and no Save, Upload, Remove, Archive or Delete buttons.

- An Edit button at the top right of the read-only page opens the current editable page, for when you do mean to change something.

- Clicking a company's name in the list also opens the read-only page, so going into edit mode is always a deliberate Edit.

- Edit in the list works exactly as it does now.

WHAT YOU'LL GET

Checking a company's details can no longer change them by accident, and changing them becomes a deliberate step.

GOOD TO KNOW

- Who can open these pages does not change: the same HR administrators who can see Organisation today can open both View and Edit. This prevents accidents rather than restricting people. If some users should be able to view companies but never edit them, that would be a separate request.

- If you'd rather the company name kept opening the editable page, reject this plan and say so.

- No change to existing records - everything already saved keeps working exactly as it does now.
