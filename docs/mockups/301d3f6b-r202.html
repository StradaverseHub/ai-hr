The deduction behaviour the request describes — any grouped type reduces the one shared figure — already works today and is unchanged. Only the starting point is wrong, and every later figure inherits that one-day error.

Why it reads 9.00

  • The pooled card was built on 13 August. It deliberately shows the smaller of two figures: what is left under the 10-day shared ceiling, and what the six grouped types hold between them. That was the right instinct — a card must never promise a day the system then refuses.
  • But the second figure is measured wrongly. Some grouped types do not hold days in their own name at all: they are set up to draw from a shared Special Leave pot. The card counts those types as holding nothing, so the pot they draw on never enters the total.
  • The apply screen does not make that mistake — it already follows the link to the pot. So the balance card and the apply screen can disagree, and the card is the pessimistic one.
  • The fix is to make the card ask the same question the apply screen asks, counting each shared pot once. The 10-day ceiling still caps the answer, so the card can never overstate.
One thing to confirm on the live system before we finalise the figure. We know from the code that at least one grouped type draws from a shared Special Leave pot, and we know the card ignores that link. What we cannot see from here is whether all six are linked and whether the pot itself is set to the full ten days. If one grouped type is simply set up with nine days of its own and no link, the card will read correctly only once that setup is completed — which is a settings change, not a code change. We will check and complete it in the same round, and report exactly what we found.

Last year's unused days. The board title says this is about entitlement carried over from last year. The request itself does not mention last year — it is entirely about the shared grouping. Carrying unused days into a new year already works today and is switched on per leave type, with a cap, an optional percentage and an expiry date. Nothing there is being changed.

Who sees the card. Where the Special Leave card appears on the Leave tab, and which of the six types are listed individually, are settings that already exist and are untouched.
