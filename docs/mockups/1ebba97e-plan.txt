THE SITUATION TODAY

When HR opens Payroll > Individual Payslip and picks an employee, the Net Pay line is actually on the page, but it cannot be seen. It sits in a coloured band near the bottom, under Earnings, Deductions and the PCB and Statutory links. The current screen style paints that band white with white writing, so it looks empty.

The amount in that band is already the employee's real Net Pay, taken straight from the processed payroll result. It is the same figure the downloaded payslip shows. Nothing is missing except the colour.

The "Matching payroll runs" row appears under the filters when one month has more than one run, for example a normal run and a bonus run. Today it is also the only way to open the second run's payslip.

WHAT WE'LL CHANGE

- Net Pay becomes clearly visible: a dark band with light writing, readable in every screen style the system offers (including dark mode). The figure, its position on the page and the downloaded payslip stay exactly as they are.

- The same fix is applied to the employee's own payslip page (My Payslip), which uses the same band and has the same problem.

- The "Matching payroll runs" row is removed. The Company, Year, Month and Payroll Cycle filters and the View Payslip button stay as they are.

- So that no payslip becomes unreachable when it is removed: if one month has more than one run that the Payroll Cycle box cannot tell apart (for example two bonus runs in the same month), the existing Payroll Cycle box lists each run separately, such as "Bonus - run 1" and "Bonus - run 2". This is the same box, not a new filter. For the usual one-run-per-month case, nothing changes.

WHAT YOU'LL GET

HR sees the employee's final payable amount at a glance, matching the payslip document, and the page is shorter and cleaner without the extra runs row. Every payslip that can be opened today can still be opened.

GOOD TO KNOW

- We're not touching how anything is calculated. Net Pay is shown exactly as payroll saved it - no recalculation, no change to payroll processing, approval, closing, payment, payslip contents, PDF or history.

- The Payroll Cycle box only grows extra entries in the uncommon month that has two runs of the same kind. If you would rather we simply always open the latest run in that case (and leave the earlier one reachable only from other screens), reject this plan and say so.
