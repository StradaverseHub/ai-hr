What this mockup promises, and what it does not.
  • Only the Employee Visibility sub-form loses a tick box; no other screen changes.
  • No leave type, balance, entitlement or application is altered. Everything already saved keeps behaving exactly as it does now.
  • Hiding a leave type from the employee’s Leave tab remains available, in the Employee Tab Placement control shown here — it is the same underlying setting the removed tick box was writing to.
  • The exact wording of the new help text and of the locked-statutory note is indicative, not final.
