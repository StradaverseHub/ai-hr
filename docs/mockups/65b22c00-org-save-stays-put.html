Why three things sit outside the one Save

A single Save Changes implies a single Discard Changes beside it. Adding a bank account, removing a statutory body, archiving or deleting a company are actions, not fields you type into — a Discard that looked like it would undo a deleted company, and then did not, would be a button lying about what it does. The Employment Information screen leaves its emergency contact list outside its own single Save for exactly this reason.

Which control sits in which group is written down and shown to you before anything moves. Sketch only — wording, spacing and colours will differ from the finished screen.
