4Two values you can use that the system already works out

Calendar days in the month
31 in August, 30 in September, 28 in February. So Basic salary / Calendar days in the month × Days worked is written once and never edited again.
Not the same as "Days worked", which is already available and is reduced for someone who joined or left mid-month.
Prorated basic salary
Basic salary after the joiner and leaver rules payroll already applies. Use it instead of rebuilding proration inside a formula, so the formula and the payroll run can never disagree.
Working days in the month and working hours per day are not included — the system has no single answer for them, because it would depend on which roster or shift is counted and employees have different ones.
