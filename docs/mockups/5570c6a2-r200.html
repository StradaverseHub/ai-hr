What this drawing does and does not promise
  • The leave types shown are examples of names in use, including the reporter's own example, Caregiver Leave. Which types are marked as needing a document is HR's own setting, and any type set that way loses the wording in the same way.
  • The same list is used by the Replacement Leave Request window, so the wording disappears there too.
  • Nothing else on this window changes: the same leave types remain available, and balances, dates, durations and approval routing are untouched.
  • Not drawn, and unchanged: HR's own leave type settings screen still shows and controls the document requirement, and a request that still needs a document is still refused at submit time with a message naming the leave type.
