Company Code — catch the duplicate, don’t forbid it

You asked for both a required field and a duplicate check. We are proposing one of them, and telling you why.

What we propose — tell you at the moment it matters

A hard rule would do this

Add New Company
Company code *
CHCE
This code is already in use. You cannot save.

Correct, and unhelpful: it stops the work until somebody resolves a naming question they may not be able to answer today.

What we propose instead

Add New Company
Company code
CHCE
Chin Hin Construction Engineering Sdn Bhd already uses this code.
It names the company that already has it, so you can tell an accident from an intention — and you can still save if you meant it.

A required field would block seven of your companies from being edited and saved until somebody invents a code for each. An enforced unique rule would reject the two highlighted rows the first time anyone touched them — and would decide, permanently, what a code is allowed to be. Neither is a decision a form should make for you.

The warning gives you what you actually asked for — not duplicating codes by accident — without either of those consequences.

If you do want the hard rules

Say so and we will build them — but tidy first. We will give you the list above as a report so you can fix “PRIVATE CO.” and the one holding a legal name, and fill in the seven blanks. Turning on the rules after that costs nothing and breaks nothing; turning them on now would leave you unable to save two of your own companies.
