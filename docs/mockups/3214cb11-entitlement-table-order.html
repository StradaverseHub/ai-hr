What about the other leave types? The other eight leave types that have entitlement tables use three names each — PERMANENT, CONTRACT - SPECIAL and CONTRACT - RETIREE. The same rule sorts them the same way: Permanent first, then Contract, then Contract (Retiree). Any future table whose name does not follow the Permanent / Contract / Part timer pattern is listed after the ones that do, in alphabetical order, exactly as the request asks.
