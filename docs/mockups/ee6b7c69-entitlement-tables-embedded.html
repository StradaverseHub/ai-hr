3A fault we have to fix at the same time found while planning this

Not reported — found by reading the editor. It would corrupt your days the first time you edit a saved table.

TODAY — press Edit on a saved table
From year(s)To year(s)Entitled days

The saved table says 0–2: 12.00 days. The boxes open blank — the editor keeps showing the empty new-table form it was already displaying.

And a blank days box saves as zero. Press “Save as a new version” and the running table becomes 0 entitled days for everyone it covers. Nothing warns you.
AFTER — Edit opens the real figures
From year(s)To year(s)Entitled days

Edit loads the table you clicked, every time — and clicking Edit on a second table replaces the figures instead of leaving the first table’s.

No saved data is at risk today, because there are no entitlement tables yet. But this is the first thing that would go wrong once you start using them, so it is fixed as part of this work.
