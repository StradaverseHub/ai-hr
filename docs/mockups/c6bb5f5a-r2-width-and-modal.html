What the change costsTHE TRADE

Small, but real, and we would rather draw it than have you find it.

The address stops being shareable
Today the open form has its own web address, so a link to “fix 25 August” can be bookmarked or sent. A pop-up has no address of its own. We keep the old link working so nothing already saved breaks, but new ones will not be created.
The “also waiting for you” rows need care
Those rows come from other sections, and today the link both opens the form and switches section so the request is filed under the right kind. That has to be carried across deliberately, or a request lands under the wrong heading.
The absent-day route must come with it
On an absent day the screen offers two answers — request a correction, or apply for leave for that date. The leave option sits outside the form today, so it has to move into the pop-up, or it quietly disappears.
One thing we are reading as a wording choice rather than a feature. The request says “Save/Submit”. There is no draft state for an attendance request — it is pending, approved, rejected or cancelled — so a Save that does not submit would be a new concept rather than a second button. We are building one confirm button beside Cancel. If you did mean a saved draft you can come back to, reject this plan and say so, and we will price it separately.
