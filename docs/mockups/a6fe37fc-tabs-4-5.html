There are exactly two rows and there is no way to add a third. An exception can only step in where the system already stops an application, and those are the only two places it does: not enough notice, and not enough balance. A new kind of exception would mean changing the part of the system that calculates and checks leave — the part this plan deliberately does not touch. If you want one, it is a separate request and we will plan it on its own.
