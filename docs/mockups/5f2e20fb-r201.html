What the drawing shows
  • The Filter button sits on the top row of the My Leave History box, on the right of the existing record count. Nothing else on the My Leave page changes.
  • Opening it reveals Leave type (tick as many as you like), Start date and End date, then Apply.
  • Applied filters appear as removable tags under the top row, so it is always visible why the list is short. Each tag drops one value; Clear all restores the full history.
  • The count reads “3 of 14” while a filter is on, and returns to “14” when cleared.
  • Leave type, Start date, End date, the tags, Apply and Clear all already exist word-for-word in all six languages.
