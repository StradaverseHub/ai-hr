4Two items we are leaving out, and why

✗Wi-Fi network whitelist. A web browser is not allowed to tell us which Wi-Fi network a laptop or phone is on — no browser on any device exposes it. This one only becomes possible with a dedicated phone app, so we would rather not put a box on screen that quietly enforces nothing.
✗Device restriction by type (Mobile / Web / Kiosk). There is no phone app and no kiosk today — clocking happens in the browser, plus files imported from a terminal. A per-company “only from a registered device” control already exists and does the real work. We will revisit the type list when there is a phone app to restrict to.
