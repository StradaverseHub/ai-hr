What that page also does — and this is the part to look at

It is not only a guide. It carries the full readiness check for every company.

CompanyCheckStatusWhat it means
ABC ManufacturingPayroll cycleOkReady to open a run
XYZ TradingPay modesBlocker2 employees on a custom period — payroll cannot run
FiammaStatutory packWarningRates are from an older pack version
Chin Hin PropertyDefault cycleBlockerStored default names a cycle that is no longer active

Payroll Settings shows a cheap subset of this deliberately, to stay fast, and defers to this page for the full per-company report. Delete the page and the full report goes with it.

So we are proposing: remove the menu row and the guidance prose, and move the readiness report onto Payroll Settings, where the short version already lives. You lose the page you do not use and keep the check that tells you which company cannot run payroll and why.
