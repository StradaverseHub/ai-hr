Sketch for the Hide / Show Employee List layout. Wording, spacing and colours will differ slightly in the built screen. The employee names, employee IDs and all ringgit amounts below are made up for this sketch — no real employee or real pay figure appears here. Column names, control captions and filter labels are the real ones.

Nowtoday, on every payroll screen with an employee list

The Hide employee list control sits in its own row at the top of the LEFT column. Because it is inside that column, it pushes the employee list down — so the employee card and the detail card no longer start on the same line, and a band of empty space opens up on the right.

The sideways strip goes away
It was a second copy of the same control. With the control on the header row there is nothing left for it to do, and removing it is what returns the last of the width.
The same on every screen
Fixed Transaction, Individual Transaction, TP1 Relief, Zakat and Loans all get this one layout, so the control is in the same spot wherever you meet it.
On a phone or tablet
The two columns stack, so the control stays directly above the employee list where you already reach for it, rather than below the whole list.
