VERDICT: Partly there already   ·   SIZE: Moderate

THE SITUATION TODAY

At the bottom of the main menu there is one section called System Configuration. Inside it are two dropdowns: another "System Configuration" (holidays, email settings, scheduled actions, audit trail and so on) and "Security Center". So an administrator opens System Configuration, then opens System Configuration or Security Center again before reaching the page they want.

Inside the Security Center dropdown, the first entry is also called "Security Center" (the overview page), which repeats the name of the menu it sits in.

WHAT WE'LL CHANGE

- System Configuration and Security Center become two separate sections in the main menu, each with its own icon: a gear for System Configuration and a shield for Security Center.

- Opening System Configuration shows its pages straight away (Holidays, Approval Delegation, Email delivery, Email templates, Workflow notifications, Scheduled actions, Data Privacy, Audit trail and the rest, as today). There is no second "System Configuration" dropdown inside it any more.

- Opening Security Center shows its pages straight away, in this order: Security & Permissions, Password Policy, Function Access, Users, Create a Login Manually, Invite a User. These are the pages that are in Security Center today; nothing is removed.

- The repeated "Security Center" entry inside the Security Center menu is removed. The overview page itself stays, and is still reached from the page heading trail and the "Back to Security Center" links on each security page.

- Each person sees exactly the same pages as today. Who can open each page does not change, and no user, role or security setting is reset or touched. Someone who may only see some security pages sees only those, now under Security Center.

- The new layout works the same in every screen style, on mobile, in search and in the page heading trail.

WHAT YOU'LL GET

Administrators reach configuration and security pages in one step from two clearly named menu sections, with no repeated entries.

GOOD TO KNOW

- Data Permission Access: this page does not exist yet. It is part of your separate request "Enhancement of Security Center - Role and User Groups, Data Permission Access and User Access Assignment", which is still being built. When that request is delivered, Data Permission Access will appear in this new Security Center section, after Password Policy, as you listed. This plan only rearranges the menu; it does not build that page.

- Function Access, Create a Login Manually and Invite a User were not in your suggested list, but they are Security Center pages today. We keep them there so nothing becomes harder to find. If you would rather move or hide any of them, reject this plan and say which.

- This changes only the menu. No page, setting or permission changes.
