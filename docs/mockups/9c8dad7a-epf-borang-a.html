The file you attached is not a blank KWSP page. It is a completed Borang A produced by another payroll system on 12 August 2026. That makes it an excellent specification — it shows exactly which boxes you expect filled — but it is not a page we can print onto, and KWSP publishes no blank one. So we draw the page ourselves to match yours line for line, and label it on the shelf as the agency's own layout drawn by us. CP22 is the only form here that comes out on a genuinely government-issued page, and we will not claim otherwise for this.
A Borang A form is not the KWSP upload file, and nothing new has to be stored. We already build agency upload files for tax and for SOCSO / EIS; both are marked draft because no portal has accepted one yet. You asked for the form, and this is the form. Your EPF reference number, every employee's EPF member number and the representative block are all existing fields — the work is filling them in and drawing the page, not adding new places to store things.
