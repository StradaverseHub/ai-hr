Choosing company, year and month, seeing the figures, the person-by-person list of anyone missing a number, and downloading as PDF, Excel, CSV or print — all of that already works today. What is added here is the status line at the top, so the generate screen says the same thing the card said.

One thing from the request is deliberately not here: a Payroll Cycle picker. A month’s statutory return is one filing covering every payroll run in that month, and this screen already adds them all together — a cycle picker would let someone file part of a month by accident.
