HOW TO READ THIS CATALOGUE
The group and section qualify repeated labels such as Status, Name and Effective date. Types describe the permitted report treatment. Current-only means historical values must say Unavailable for this date unless an authoritative dated record or snapshot exists. Restricted access below is the proposed report permission, not a claim that today’s screen already has that control.

EXPLICIT SCOPE BOUNDARIES
- Data privacy (PDPA): This Personnel section contains explanatory text and a link, not a saved Personnel field. Privacy case data belongs to its own screen and is not exposed automatically.
- Disciplinary: No separate disciplinary tab/register is rendered by the current Personnel screen. Existing blacklist status/reasons are included under Employment History. A future registered disciplinary field must opt into the restricted HR category.
- Contract history: Contract start/end/remark currently live under Employment; contract-related movements and review records are included in their actual owners. No independent contract-history register is invented.
- Full Form TP3 and payroll transaction details: The Payroll tab displays four opening-balance fields and a Zakat summary, plus links. Fields on the linked transaction screens are not silently claimed to be Personnel tab fields.
- Actions, save/discard, buttons, help text, search, paging and confirmation draft values: Interface controls are not business data columns.
- Photo and attachment binary contents: Listed for completeness but disabled as report columns. Metadata/availability can be reported; protected files remain accessible only through their existing guarded screen.
- Arbitrary audit payload properties: Only registered, typed, permission-checked Personnel fields may be selected. Generic payload dumping could expose confidential values.

HISTORICAL LIMIT
As-at date cannot recover a past value which was never retained. Past values without owner history/snapshot must show Unavailable for this date. A current value is never silently labelled historical. Current field labels/catalogue renames and mutable records need coverage decisions before implementation.
