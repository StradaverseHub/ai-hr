THE SITUATION TODAY

System Labels already has a blank Excel template and an import preview. It cannot download the current records into that template. The existing import also treats blank cells differently from the requested edit-and-upload workflow.

WHAT WE'LL CHANGE

- Rename the existing download to Download blank template and add Download template with current data on both System Labels tabs.
- Let HR choose accessible companies and lists, with all lists selected initially and inactive or archived records optional.
- Use one workbook layout for both downloads, with current references, text-formatted codes, dropdowns, frozen headers and consistent formatting.
- Extend the existing importer with Add new + update existing. A blank cell keeps the saved value, while [CLEAR] explicitly removes an optional value.
- Show New, Update and No change in the preview. HR can exclude rows, review old and new values, and see a warning when a record changed after export.
- Record each export and preserve records removed from the file. Uploading never changes Active or Archived status.

WHAT YOU'LL GET

HR can download, edit and re-upload current lists through the familiar import, without rewriting unchanged records or accidentally clearing fields.

GOOD TO KNOW

Selections exceeding a worksheet's supported row limit will receive a message to narrow the companies or lists before download. This plan uses that requested alternative rather than split worksheets. Archived rows can be included for reference; editing an archived record still requires restoring it through its existing editor first.
