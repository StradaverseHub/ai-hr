THE SITUATION TODAY

Import Employee already offers full and section templates in Excel and CSV. However, the Personnel screens and template columns are maintained separately, so labels, available choices and new fields can drift apart.

WHAT WE'LL CHANGE

- Define Personnel fields in one shared list that supplies their screen labels, sections, value types, required rules and import guidance.
- Generate the full new-employee template and each relevant section template from that list, including Family fields on the Family sheet.
- Use the same column labels as the Personnel screens, with required/optional guidance, date formats and current permitted choices by name.
- Use the same validation when entering a field on screen or importing it, and show the proposed value or specific error in Check and preview.
- Accept a renamed field's old header for one release with a warning. Removed fields will explain what happened rather than silently write old values.
- Clearly identify fields that cannot be imported and why, and add a check that catches any Personnel field missing from either the templates or that list.

WHAT YOU'LL GET

Changes to Personnel fields and Import Employee will be delivered together. HR can rely on downloaded templates to match the screens and understand what to enter.

GOOD TO KNOW

Section templates continue to update existing employees; the full template creates new employees. Blank update cells retain existing values. Calculated figures, system history, approval decisions and file attachments need their proper screens rather than a general employee import.
