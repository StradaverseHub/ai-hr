What is not changing

Two of the points you raised already work today, a third is half done, and none of the figures are being touched.

Loads only on demand

Sideways scrolling

Wide, but shared
This is the one tab already given the full width of the window — the employee list just takes about a fifth of it. Removing the list is what hands that width to the figures.
Same columns, same numbers
Twelve months plus a Total, the same pay item rows, the same Excel export. We are not touching how anything is calculated.
