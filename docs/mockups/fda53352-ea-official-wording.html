Form C.P.8A (EA) — the official wording, in both languages

Sketch for feedback item fda53352. No payroll figures are shown. Every box below already exists on the form we generate today, in this order, on one A4 page. This sketch compares the wording; the column positions also need moving, which a side-by-side of words cannot show.

One thing we got wrong, and this request caught it. Our EA prints “(C.P.8A - Pin. 2024)” at the foot of the page. LHDN does not issue a Pin. 2024 — the current form is Pin. 2023, which is what you attached. We had copied the layout from another payroll system’s version of the form, and that copy carried the wrong revision number. Your attachment is byte-for-byte the file LHDN publishes today, so from now on we work from the real thing.
