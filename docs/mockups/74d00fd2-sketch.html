Only two of the 197 nationalities contain “ind”, so those are the two rows on show. The other five you picked — Malaysian, Singaporean, Thai, Vietnamese, Filipino, Nepalese — are still picked, just not listed while you are typing.

What the two buttons do here.
  • Nothing typed — Select all ticks all 197, Deselect all clears all 197.
  • “ind” typed, as drawn — Select all adds Indian and Indonesian to what you already have. Deselect all removes only Indonesian, and the six others you picked stay picked.
  • Either way the closed box keeps a running count, so “7 selected” is visible without opening anything.
One thing to watch. Ticking every value on a field is not the same as leaving that field blank. A rule with all 197 nationalities ticked still counts as a rule that restricts by nationality, so it will beat a rule that sets no restrictions at all when both could apply to the same person. If you mean “everybody”, leave the field untouched. The box will read “All selected” whenever every value on a field is ticked, so this is easy to spot before you save.
