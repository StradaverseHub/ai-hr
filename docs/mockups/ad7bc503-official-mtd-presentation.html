The chargeable income formula, today and as the agency prints it

Today

P = Σ(Y − K) + (Y₁ − K₁) + (Y₂ − K₂) × n − [ D + S + Du + Su + Q ] − [ ΣLP + LP₁ ]

(Yₜ − Kₜ) is hidden whenever it is zero

After this change

P = [ Σ(Y − K) + (Y₁ − K₁) + [ (Y₂ − K₂) n ] + (Yₜ − Kₜ) ] − [ D + S + DU + SU + QC + ( ΣLP + LP₁ ) ]

Where (Yₜ − Kₜ) = 0

The right-hand shape, including the words “Where (Yₜ − Kₜ) = 0”, is copied from the specification's own worked examples.

Step 1 — the agency's own lettering

[A]   Determine the category of the employee
ResultCategory 3 — married, spouse working  (D = 9,000 · S = 0 · QC = 4,000)
[B]   Determine the chargeable income for the year — P
FormulaP = [ Σ(Y − K) + (Y₁ − K₁) + [ (Y₂ − K₂) n ] + (Yₜ − Kₜ) ] − [ D + S + DU + SU + QC + ( ΣLP + LP₁ ) ]
Actual values[ 56,000.00 + (8,000.00 − 880.00) + [ (8,000.00 − 880.00) × 4 ] + (0.00 − 0.00) ] − [ 9,000.00 + 0.00 + 0.00 + 0.00 + 4,000.00 + ( 1,200.00 + 0.00 ) ]
Calculation[ 56,000.00 + 7,120.00 + 28,480.00 + 0.00 ] − [ 14,200.00 ]  =  91,600.00 − 14,200.00
ResultP = 77,400.00
Note(Yₜ − Kₜ) = 0 — no additional remuneration this month
[C]   Determine the monthly deduction for net normal remuneration
FormulaMTD = [ [ (P − M) R + B ] − ( Z + X ) ]  ÷  ( n + 1 )
Actual values[ [ ( 77,400.00 − 70,000.00 ) × 0.24 + 4,400.00 ] − ( 0.00 + 3,180.00 ) ] ÷ ( 4 + 1 )
Calculation[ 6,176.00 − 3,180.00 ] ÷ 5  =  2,996.00 ÷ 5
Result599.20
FloorA negative result is treated as 0.00 (specification rules 3 and 5). Not applied here.
[D]   Determine the net monthly deduction for the current month
FormulaNet MTD = MTD for the current month − zakat and departure levy for the current month
Actual values599.20 − ( 50.00 zakat + 0.00 levy )
Result549.20
NoteX (3,180.00) is tax already PAID in earlier months and is not this line. It was deducted in [C].
[E]   Determine the total deduction for the year
FormulaX + [ Step [C] × ( n + 1 ) ]
Actual values3,180.00 + ( 599.20 × 5 )
Result6,176.00

A defect found while checking: the PDF cannot print the sigma

Downloaded PDF today

After this change

Sum(Y - K)   56,000.00

Confirmed by running the PDF's own character handling. It replaces anything it cannot print with a question mark, and the Greek sigma is one of those. No test covers the PDF's contents today, which is why this was never caught. One will be added.
