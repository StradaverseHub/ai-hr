Two notes

We are going one step further than you asked, and here is why. You asked us to remove the other eleven options and default to Replacement Leave. That leaves a dropdown with one thing in it, which still invites a click that can change nothing. The HR-side version of this same dialog already shows it as a plain fixed field. We are matching that, so the two screens agree. Say the word if you would rather have the one-item dropdown.

We will not match on the name. You asked us to filter by code rather than display name so a rename cannot break it — right instinct, and we are going slightly stronger: the system already has one official way of answering “which type is Replacement Leave”, and it survives both a rename AND a code change. We will use that one, so this box and the credit it creates cannot drift apart.
