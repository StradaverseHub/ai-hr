Two things deliberately drawn in words, not pictures

1. The SpaceX August 2026 Director Fee. We checked that run on 18 August: there is a real Director Fee transaction recorded against that employee on that run, so on that run the description is not a leftover label. 2. The paid marker. That same transaction is not marked as paid in the transaction ledger even though the payslip prints it. That is a separate repair, done in the data rather than on a screen, so there is nothing to draw — but it is what stops a later payroll run paying the same amount a second time.
