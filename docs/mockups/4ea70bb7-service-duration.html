It is calculated from the Group Join Date, recalculated every time the profile is opened, and it already handles leap years, 28/29-day February, 30 and 31-day months and month-end joiners. This request is satisfied by using that same calculation for the Join Date figure as well, and showing both on the Employment tab — not by building a new one. The date field labelled “Join Date” on this card is the group date; it will be labelled Group Join Date so the two screens agree.

In short: the module becomes Personnel Management, and both service figures on the Employment tab show Years / Months / Days worked out independently from their own dates, recalculated whenever the profile is opened. Nothing is stored, no existing record changes, and no leave entitlement or pay calculation is affected — this only changes what is shown on screen.
