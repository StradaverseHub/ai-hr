What we’ll do — the step that was always planned

When the payslip was first built we wrote down that it used a basic built-in font covering only the Latin alphabet, and that carrying a proper font was the follow-up. Nothing has revisited it since. This is that follow-up.

We will carry a font that contains these letters, and put only the characters each payslip actually uses into the file. A payslip uses a few hundred distinct characters, not the tens of thousands a full Chinese font contains — so an English payslip stays exactly the size it is today, and a Chinese one grows by a few tens of kilobytes rather than megabytes.

Nothing about the figures changes. Not one amount, total or calculation. This is only which letters the document is able to draw.

Two things worth knowing

Your government forms are not affected and are not being touched. EA, CP22, CP39, Borang A, Borang 8A, TP1 and TP3 are only ever produced in English or Malay. Nothing you file with LHDN, EPF or SOCSO changes.

If you would rather not carry the font at all, the alternative is to stop offering the payslip in the four languages it cannot print, so an employee gets a correct English one instead of a page of question marks. That is an hour of work rather than a day. Reject this and say so, and we will do that instead.
