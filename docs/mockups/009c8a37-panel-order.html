Where did Payroll period go? It is not an employee filter — it narrows the transactions on this side of the screen, not who is in the list — so it does not belong in the More filters group. Your separate request moves it up beside Search transactions, above this table. Until that one is built it stays on the panel, on its own line below More filters.

More filters, openedone click

Click More filters and the four narrowing choices appear, exactly as they read today. They stay open while you are on the screen, and start closed again next time. When a filter is on while the section is closed, the line says how many — so a shortened list is never a mystery.
