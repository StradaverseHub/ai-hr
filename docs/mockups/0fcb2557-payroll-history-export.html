Each named allowance becomes a column of its own. Handphone Allowance is no longer a line buried inside one opened payslip — it is a column you can sort, total and filter like any other. A named item that is not on a given payslip leaves its cell empty rather than printing a nought, which is why Travel Allowance is blank on Ismail's row.
Figures, not text. The cells hold numbers — 5600.00, not “RM 5,600.00” — so selecting a column totals it in one click. There is deliberately no grand-total line at the bottom: a totals row sitting inside the data is what breaks Excel's own sorting and filtering.

The deduction columns add up to Total Deductions, and the employer columns add up to Total Employer Contributions — RM 836.25, the same figure the screen shows. SKBBK, CP38 and Zakat are there so the arithmetic closes even when they are nil, as they are on this run. The download is not limited to the number of rows the screen stops at; it carries every payslip your filters match.

Three things we have deliberately left in words rather than drawn

Where the named columns will be blank. Bonus, off-cycle and adjustment runs never recorded per-item detail, and neither did runs calculated before this payroll started keeping it. On those rows the summary figures and the Allowances total are still exact and the named columns are simply empty. We have not drawn an example, because we cannot yet tell you which of your runs it will be — the file itself will say so at the top.
One wide sheet, not the two you asked for. The sketch shows a single tab on purpose. A single table is what Excel's sort, filter and pivot tools work on; two sheets would leave you matching rows up by Employee ID and period by hand. If you would rather have the two-sheet version, reject this plan and say so.
Nobody else's numbers. Every figure in this sketch is Ismail's own, taken from the screenshot you sent. We have left the other rows blank rather than fill them with plausible-looking amounts for real colleagues.

Nothing about your payroll changes. No figure is recalculated — the file reads the same saved figures the screen reads, which is why it cannot disagree with it. Access is unchanged: only administrators reach this screen, and a download can only ever contain the companies you are already allowed to see.
