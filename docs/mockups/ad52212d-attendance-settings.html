What is already built, and what is not. Shift already supports multiple paid and unpaid break windows, cross-midnight, split shifts, half-day first and second ranges, and flexible shifts. Overtime already has bands with hours-from, hours-to, a rate, a separate public-holiday rate, and the up / down / none rounding with a typed number of minutes that went live this week. Genuinely new: the Settings grouping itself, Duplicate and Activate / Deactivate, refusing to delete something an active Work Schedule still uses, the four-step wizard — and on Overtime Pattern, choosing which shifts it applies to and selecting day types.

Built in four passes, in that order, so the menu tidy-up you asked for is not held up by the wizard.
