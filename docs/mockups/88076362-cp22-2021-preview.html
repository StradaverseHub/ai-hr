  • 01One page becomes two. Sections A, B and C on page one; D, E and F on page two.
  • 02The printed character cells are gone. Tax number, identity card, passports, dates and phone are plain boxes on the 2021 page. Everything we do today to place one letter per printed cell stops applying.
  • 03Addresses change shape. Three free rows plus separate Poskod, Bandar and Negeri boxes. Today we fold postcode, town and state onto the last address row — on the new page that would leave three printed boxes empty.
  • 04Monthly pay is itemised. One rate box and three allowance rows become eight numbered lines with a total, plus two "specify" lines.
  • 05"To" is gone. The 2021 page has no box for the branch you file with. It stays on the review screen and in the text download; it cannot print.
  • 06About 50 entry areas, up from 33 — every one re-measured from the new page itself, never nudged by eye, then checked by printing a test copy where every multi-row block is deliberately one line too long, viewed in two independent readers.

The copy you attached is stamped "Untuk Rujukan Sahaja" — for reference only. That is how LHDN publishes it now: since September 2024 a CP22 goes through e-CP22 on MyTax and a printed one is not accepted. We will take LHDN's own current copy when we build. If it still carries the stamp, so will yours, and the screen will say why — we will not quietly erase a government stamp off a government form. The stamp is drawn faintly on the two page sketches above so you can see exactly what it is.
How we will know it is right, not just green. The last time this renderer changed, a form passed every automated check and still silently dropped the fourth line of an address and one allowance line — the boxes simply looked full. So the test is a printed copy where every multi-row block is deliberately one line too long, read in two independent PDF readers that fail differently. If they disagree, it is not fixed.
