Door 2 — the Transaction Entry card, unchanged and still there.

What is actually being removed

One menu row. Nothing else. The Loans screen keeps every field, every button and every permission it has today. Anyone who can open Loans now can still open it afterwards, and anyone whose access you have turned off stays turned off — the screen is still listed on your access settings by name, exactly as it is now.
This is a return to how it used to be, not a new arrangement. Loans was originally reachable only from the Transaction Entry card; the menu row was added later. Taking it back out puts Loans where a payroll input belongs — beside the other things you key in before a run — instead of offering the same screen twice in one menu.

Existing links and bookmarks to the Loans screen keep working. Its address does not change.
