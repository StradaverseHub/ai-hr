“Change employee” hides or shows the list without leaving the tab, and the tab remembers your choice next visit — so a wide table such as History can still be given the full screen width.
In words

Parts deliberately left as words rather than drawn

  • History keeps every filter it has today — company, year, month and payroll cycle stay in the filter row exactly as they are; only the employee dropdown becomes the search panel.
  • Individual keeps its filter row too — pay item, department, transaction status, created by and the created-date range are untouched.
  • Nothing is forced. Leaving the selection on “All employees” shows exactly what each tab shows today, so no existing way of using these tabs is taken away.
  • No figures move. This changes how you pick a person, not what is shown, calculated or exported.
  • The panel lists the first 25 matches and says how many more there are, so you refine the search rather than scroll — the same behaviour Transaction Detail has today.
