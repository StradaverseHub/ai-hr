Multiple departments and other assignment values already work, but the current selection boxes make this difficult to discover. Ordered approval levels and alternative approvers also exist; their editor needs to follow the clearer Leave Approval Template pattern.

WHAT WE'LL CHANGE

- Show each company once, with View/Edit opening that company's Attendance Irregularity and Self Overtime tabs.
- Move each application's routing control and workflow list into its tab. Show code, name, assignment, approval-level summary, priority, status and actions.
- Replace the assignment boxes with searchable selections that clearly show chosen departments, business units, divisions and job grades, with controls to add or remove each choice.
- Keep the chosen company fixed for each workflow. Values within one assignment field are alternatives; different filled fields must all match. Empty fields mean all eligible values in that company.
- Follow the Leave editor's Approval Mode and ordered-level design. Sequential Approval uses one approver per level; Any One Approver allows alternatives within a level. Levels still proceed in order, and later levels cannot approve early.
- Retain Attendance's supported Direct Manager and HR Administrator choices. Add, edit, reorder and remove levels, with clear Save, Cancel and assignment preview controls.
- Preserve saved versions, requests already awaiting approval, actual decision history and company access restrictions.

WHAT YOU'LL GET

One clear starting point per company, understandable assignment selections and a familiar approval editor whose displayed rules match how requests are approved.

GOOD TO KNOW

Any One Approver clears only the current level. It does not let a later approver skip earlier levels or approve the entire application immediately. Leave-specific approver types are not added to Attendance by this change.
