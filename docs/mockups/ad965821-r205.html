What we are deliberately NOT drawing

No explanatory line under the list

The previous plan proposed a short caption saying "some leave types have been left out — check your profile". That is now dropped. The employee is given no signal at all that a filtered-out leave type exists.

Some leave types are not shown because of your profile details.  — removed from the plan
  • No greyed-out or disabled rows.
  • No "unavailable" badge, tooltip or footnote.
  • No count of what was removed.

Which HR settings decide what appears

The setting HR already hasWhere HR sets itEffect on the list
Condition → Criteria: Gender, Marital Status, length of service, probation status, and the eight organisation criteria HR Admin → Leave Config → Leave Type → Condition A type whose criteria the employee does not match is absent from their list
Employee Tab Placement set to Hidden HR Admin → Leave Config → Leave Type → Employee Visibility Absent from the list, for everyone
Employees can apply for this leave type — unticked HR Admin → Leave Config → Leave Type → Employee Visibility Absent from the list, for everyone

Three settings, no fourth one

These are the three switches that already exist. Last round the duplicate "Visible to employee" tick box was removed so each of them means exactly one thing. This item adds no new switch — it simply makes the Request Leave list obey the three you already have.

What does not change

The refusal stays behind the screen

The system still checks eligibility again when the form is submitted, and still refuses an application it should not accept. Hiding the option is the courtesy; refusing the submission remains the control. Nothing about entitlement, balances, accrual, approval routing or payroll is touched, and no existing leave record changes.

A blank Gender or Marital Status hides the restricted type

An employee whose Gender or Marital Status is not filled in does not match a rule that asks for one, so that leave type does not appear. That is already how the system decides at submit time today, and it is the safe default. With no explanatory line on the screen, the way this surfaces is an employee asking HR where a leave type went — and the answer is to complete the profile.
