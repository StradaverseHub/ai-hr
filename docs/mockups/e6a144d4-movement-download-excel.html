Already on your screen today New — the file has room the screen does not Only the column headings are drawn. The cell values are not sketched, because four of these columns are not on your screen and we are not going to invent them.
Event Status (column B)
Applied, Pending, Reversed, Cancelled, Corrected or Superseded, spelled out on every row so you can sort and filter inside Excel. Your five read Applied, Applied, Applied, Pending, Pending.
Currency and Basic Salary (K and L)
Your screen shows MYR 4500.00 as one piece of text. The file splits it — MYR in Currency, 4500.00 in Basic Salary as a real figure, so it can be summed and charted the moment the file opens.
Recorded At (D)
When the event was keyed in, as against the date it takes effect. It is not editable, and it is not shown anywhere on the tab today.
End Date and Remarks (E and M)
Both were taken off the on-screen table to save width. A spreadsheet has room for them, so they come back.
Section (I)
The screen has never shown it. On your rows Division already prints a dash, which means these placement fields have not been filled in for this employee — Section may come out blank at first and will fill itself in as soon as they are.
Correction Reason (N)
The reason someone typed in when an event was rolled back or cancelled. Blank on events that were neither.

Every event, including the ones the profile keeps out of sight. The file always carries the rolled-back, cancelled, corrected and superseded entries too, with the status spelled out on each row. Your employee has none of those — which is why your screen shows all five events, and why the download will hold exactly those five. We have not drawn an employee who does have them.

The file itself. An Excel workbook of the same kind the Payroll and Leave downloads already produce, so it behaves identically. Excel, Numbers and Google Sheets all open it by double-click. It is not the newer package format, so the name ends .xls rather than .xlsx. The name is built from the employee's own ID and name followed by EmploymentHistory, so a folder of them sorts itself — your screenshot is cropped above the header, so we have not guessed at the name to print here.
