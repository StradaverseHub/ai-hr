THE SITUATION TODAY

1. Each screen sets its own label style. The same kind of label is small grey text on one screen, bolder black text on the next, and small capitals on a third.

2. The New Mapping page puts three fields side by side in narrow columns. On a mid-size screen the Delimiter choices wrap inside their box.

3. Every list is a wide table (up to 8 columns). On a phone the page has to be scrolled sideways to see the status, the error or the actions.

4. On a fixed-width file, the field names sit in tiny type above the numbered ruler. Short fields or longer translated names can print over each other, and the ruler runs off the side of the screen.

5. The import counts are a grid of boxed tiles, and the import log puts the recent imports table inside the log's own section.

WHAT WE'LL CHANGE

The same rules apply on every screen below, in both the standard look and the Classic look:

- Sections: each group of information sits in one section with a number and a clear heading (for example "01 Details"). In the standard look a section is a thin dark line on top; in Classic it is a light white card. Never a section inside a section.

- Labels and values: on a computer the label sits on the left in a fixed-width column and the value on the right, so every value starts at the same place. On a phone the label sits above its value. Long labels wrap onto a second line instead of being cut off.

- Text: four styles only, used the same everywhere: section heading, field label, field value, and helper text in a lighter shade under the field it explains.

- Lists: a table on a computer. On a phone each row becomes a small block of labelled values, so nothing scrolls sideways.

- Statuses (Active, Valid, Completed with Errors and so on) keep their words and colours, written the same way on every screen.
