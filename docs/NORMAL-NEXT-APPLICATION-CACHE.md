## Build contract

The normal build job now uses next-application-cache.mjs through pnpm exec tsx. It always generates current Next types, then invokes the canonical System Testing production builder with --ci. A restored graph cannot supply PASS or replace compilation, the production application TypeScript check, a fresh System Testing UUID, a fresh BUILD_ID, packaging or any required release check. The resulting production-build-v1 packet remains mandatory.

The wrapper checks the five compiled System Testing values against the actual new preparation. It also requires actual successful compiler/build output and the original compiler configuration. On compatible context, the post-build graph is validated and copied before only its owned working state and private record namespace are removed. The compiled .next output stays on the disposable runner for the existing optional Turbopack cache upload.

## Optional graph input

The next-application-state-v1 packet contains seven JSON members: build-log, build-provenance, envelope, producer, state, successful-build and system-testing. It is separate from both the mandatory production-build-v1 bundle and the whole-project compiler cache.

Discovery considers at most three recent normal runs and one independently verified immutable bootstrap tuple. A usable managed producer needs:

- Actual company repository identity, first attempt, non-PR event and successful unique build job. A different failed job keeps the whole run failed.
- Complete bounded API job/artifact inventories, the fixed artifact namespace, producing-job artifact time, API digest and actual downloaded ZIP length/digest.
- Actual authenticated controller Git blobs matching every current critical builder/context/compiler/resource/extractor/workflow implementation. Self-reported code hashes are insufficient.
- Exact seven-member packet, actual successful canonical phase and compiler log, source/controller/build/record identity and owned cleanup.
- Unexpired state no older than24hours, complete bounded ancestor comparison, and exact current runtime/dependency/compiler/configuration/CSS/generated-type/source-path/heap context.
