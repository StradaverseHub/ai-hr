AIHR · Monolith · design language

A quiet instrument with one heavy object.

Bone paper, hairlines, one typeface set large and tight, mono labels with index numbers, and a single colour used as a mark, never as a fill. Every screen gets exactly one black glossy object, built as a real solid, that also works as an instrument. The intent bar does the work; navigation is seven words.

Grid and rhythm

Content width 1328 inside 56 px gutters. Twelve columns, drawn faintly on the page so the system is visible. Sections start with an ink hairline and a mono label; rows and cells divide with bone hairlines. Vertical rhythm is 30 px between sections, 0 inside lists. Nothing has a shadow except the object.
Every screen has the same skeleton: wordmark and seven-word nav, headline with its object, the intent bar, numbered sections, a ruler, and a status line at the foot.

The object

One per screen. Black, glossy, a real solid in CSS, slow, and useful: each carries one orange mark that means something.
MonolithHome. Twelve etched months; October burns.
PlatesPayroll. One plate drops per stage of the run.
SlabLeave and claims. The request or claim itself, as a card.
TabletsStatutory. One per authority; the due ones are marked.
OrbPeople. The selected person, with reports on a ring.
ClockAttendance. The orange hand is now.

Navigation

Intent barThe primary way to do anything. "Go to" lists every route for keyboard users.
Seven wordsHome, Payroll, People, Leave, Time, Claims, Statutory. Mono, underlined when current. Sub-views are words too.
RulerThe as-at control at the foot of admin screens. A navigation control through time.
Status lineA cockpit readout at the foot: system state, counts, next deadline.
