THE SITUATION TODAY

Security & permissions currently opens a long page that combines the access guide, account creation, invitations and user management. The editable security settings already have a separate screen, but are reached through that page.

WHAT WE'LL CHANGE

- Rename the System Configuration entry to Security Center. Open a clear settings overview, following the existing Payroll Settings layout.

- Provide five independent pages: Security & Permissions, Function Access, Create a Login Manually, Invite a User and Users. Each will have its own title, relevant controls and a way back to Security Center.

- Show the available pages in the left navigation and overview. Each person will see only the pages and actions their existing permissions allow.

- Keep existing user records, permissions, invitation options and account-creation rules. Account forms and their success or error messages will stay on the relevant page.

- Keep user-list filters and management actions, including activation, invitations and unfinished account setup. Existing links will lead to the appropriate page without losing the selected person.

WHAT YOU'LL GET

Administrators can go directly to the security task they need, without scrolling through unrelated sections. The five pages will use consistent spacing, headings and controls across supported screen sizes and languages.

GOOD TO KNOW

- Function Access currently explains which roles can open each screen. It will retain that guide; supported permission changes remain on Security & Permissions.

- Moving a form will not give anyone new authority to create accounts, invite users or change access. The attached screens show proposed navigation with fictional examples.
