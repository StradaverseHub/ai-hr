本指南面向希望查看自己剩余假期并申请休假的**员工**。读完本指南后，你将知道如何查看假期余额、提交申请、了解点击提交后会发生什么，以及每种状态的含义。你可以在应用的两个位置完成这里的所有操作：**Leave** 页面和你自己的 **My workspace** 页面。

## 在哪里找到假期

在左侧边栏中，你有两个入口：

- **Leave**（`/leave`）— 共享的假期页面。顶部是一个 **Planned absences** 时间线，显示在 14 天窗口内谁不在岗，接着是你的余额、一个 **Requests** 表格和一个申请表单。
- **My workspace**（`/me`）— 你的个人页面。它有一个紧凑的 **Leave** 卡片，显示你的余额、一个快速申请表单以及你最近的几条申请，全部集中在一处。

**提示：**如果你想快速完成"我还剩多少天，让我订一天假"，**My workspace** 上的 **Leave** 卡片是最快的途径。当你想查看计划缺勤时间线或你的完整申请历史时，请使用完整的 **Leave** 页面。

## 查看你的余额

你的余额是**仅对你自己可见**的。在 **Leave** 页面上，余额卡片的标题是 **My balances**，只显示你自己的行——你在那里看不到同事的余额。（只有 HR 和管理员这两个角色才能看到所有人。）副标题写着 **available / entitled**，它告诉你如何理解每个数字。

每种假期类型会显示类似 `12 / 16` 的数字：

- **第一个数字**是你现在仍然可以预订的天数（**available**，可用）。
- **第二个数字**是你本年度的总额度（**entitled / accrued**，应得 / 累计）。

在 **My workspace** 上，**Leave** 卡片为每种类型显示相同的 `available / accrued` 数字，外加一个小的使用条和下方的一行摘要：

| 术语 | 含义 |
| --- | --- |
| `used` | 已批准并已休的天数 |
| `pending` | 你已提交但尚未决定的申请中的天数 |
| `available` | 仍可预订的天数 = entitled − used − pending |

使用条以两种深浅填充：实色部分是你**已使用**的假期，较浅的部分是**等待批准**的假期。在 Leave 页面的余额网格中，待处理的申请还会在数字旁边显示一个小的琥珀色 **{n} pend** 徽章，将鼠标悬停在某个单元格上会显示类似 `2 used · 1 pending approval` 的提示。

**注意：**有些假期类型不累计年度余额（例如某些按次计算的病假）。这些类型显示一个破折号（`—`）而不是数字——这是正常的；只是没有可供倒数的累计余额，但你仍然可以申请它们。

**关于马来西亚假期的说明：**年假、病假和住院假根据你的服务年限作为年度额度授予，符合《雇佣法令》（Employment Act）。随着服务年限的增加，等级会自动提升，因此你的 **entitled** 数字会随时间增长。

## 申请休假

你可以从任一页面提交。两个表单创建的是相同的申请。

### 从 My workspace（最快）

1. 在左侧边栏中，点击 **My workspace**。
2. 找到 **Leave** 卡片以及余额下方的小表单。
3. 从下拉菜单中选择一个 **Type**（你可用的假期类型）。
4. 选择一个 **From** 日期和一个 **To** 日期。两者都是必填的。
5. 点击 **Request leave**。

你的新申请会显示在同一卡片下方的 **Requests** 中，并带有一个状态标签。

### 从 Leave 页面

1. 在左侧边栏中，点击 **Leave**。
2. 滚动到底部并点击 **+ Request leave** 以展开表单。
3. 填写：
   - **Employee** — 你自己（之所以有这个选择器，是因为经理和 HR 可以代他人提交）。
   - **Leave type** — 你想要的假期类型。
   - **Start date** 和 **End date** — 两者都默认为今天；将它们改为你的日期。
   - **Reason (optional)** — 一条简短的备注，例如 `Family trip`。你可以留空。
4. 点击 **Submit request**。

### 天数是如何计算的

你不需要输入天数——系统会根据你的日期算出来：

- 对于**工作日**类型的假期（例如年假），它只计算工作日，并**跳过你所选范围内的周末和公共假日**。
- 对于其他类型，它计算范围内的每一个日历日。

因此，一个跨越正常周末、从周五到周一的年假申请会被计为 **2 天**，而不是 4 天。如果你的范围算出来是零天（例如结束日期早于开始日期，或者整个范围都是周末），该申请将被拒绝并显示错误——请选择有效的日期并重试。

## 各状态的含义

每条申请都带有一个状态，显示为彩色标签：

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| `Pending` | 琥珀色 | 已提交并等待决定。它已经作为待处理项计入你的 **available** 余额。 |
| `Approved` | 绿色 | 已批准。天数已从你的余额中扣除。 |
| `Rejected` | 玫红/红色 | 被驳回。不扣除任何天数；你的待处理数额会重新释放。 |
| `Cancelled` | 灰色 | 申请已撤回，不再有效。不扣除任何天数。 |

在完整的 **Leave** 页面上，顶部横排的四张卡片（**Requested**、**Approved**、**Pending**、**Rejected**）也是筛选器——点击其中一张可只显示处于该状态的申请，点击 **Requested** 可清除筛选。

## 谁来批准你的假期

当你提交时，你的申请会进入 **Pending**，并由拥有审批权限的人审核——通常是你的**经理**或 **HR**。有几件事值得了解：

- **你不能批准自己的假期。**即使是经理也不能批准自己的申请；Approve/Reject 按钮永远不会出现在你自己的行上。
- 在批准时，系统会检查你是否确实有足够的余额。如果某个已批准的申请会使余额降至零以下，批准将被阻止并显示余额不足的消息——因此一条申请可能会一直处于待处理状态，直到该问题得到解决。
- 你在自己的视图中不会看到 Approve/Reject 控件——那些属于审批人。经理和 HR 还有一个专门的 **Approvals** 收件箱。

## 取消申请

`Cancelled` 状态用于已撤回的申请，但目前在员工的 leave 页面或 My workspace 页面上没有自助式的"Cancel"按钮。如果你误提交了一条申请或你的计划有变：

1. 联系你的**经理**或 **HR**（处理 **Approvals** 的人）。
2. 如果申请仍是 `Pending`，请他们**驳回**该申请；如果已经是 `Approved`，请他们撤销它。

无论哪种方式，一旦该申请不再是 `Approved`，天数就会返还到你的余额中。

**提示：**在提交之前，仔细核对你的 **From**/**To** 日期和 **Type**——一次填对可以避免与审批人来回沟通。

## 故障排除与常见陷阱

- **我的余额显示一个破折号（`—`）。**那种假期类型不带累计年度余额（例如按次计算的病假）。你仍然可以申请它。
- **"No leave days in range" 错误。**你的 **To** 日期早于你的 **From** 日期，或者对于工作日类型的假期，整个范围都落在周末/假日上。请调整日期。
- **我看到的天数比预期少。**工作日类型的假期会跳过周末和公共假日，因此一段日历跨度通常会被计为更少的假期天数。
- **我的申请卡在 `Pending` 上。**它正在等待你的审批人。如果紧急，请催一下你的经理或 HR——并且记住，如果余额不足以覆盖申请，批准可能会被搁置。
- **我看不到任何其他人的余额。**这是设计如此——余额对每位员工都是私密的。只有 HR 和管理员才能看到全貌。
