本指南适用于使用 **员工自助服务** 来更新个人信息并参与绩效考核的员工。你将学到如何在几秒钟内自行更新联系信息、如何提交需要先经过审批的影响薪资的信息变更（银行账户和 PCB/税务类别），以及如何完成自我评价并在经理的评价发布后予以确认。

这里的一切都集中在一个地方：在左侧边栏中，点击 **员工自助服务**（`/me` 页面）。向下滚动到 **我的资料** 卡片，再往下是 **我的评价** 表格。

## 更新你自己的个人资料

你的个人资料按风险分为两半。低风险的 **联系** 信息你可以直接编辑。**银行与税务** 信息会影响你的薪资，因此需要通过审批申请来处理。两者并排显示在 **我的资料** 卡片内。

### 你可以直接编辑的联系信息

在 **我的资料** 卡片的左侧，在 **联系信息更新即时生效** 这条说明下方，你可以编辑：

- **电话**
- **地址**
- **出生日期**
- **紧急联系人**（姓名）
- **紧急联系电话**

更新方法：

1. 在左侧边栏中，点击 **员工自助服务**。
2. 滚动到 **我的资料** 卡片。
3. 在上述任意字段中输入新值。你可以一次更改一个或多个。
4. 点击 **保存资料**。

就这样——更改会立即保存。没有审批步骤，也无需等待。

**注意：** 此表单只会修改你的联系字段。你的姓名和电子邮箱属于你的身份记录，无法在此处更改——如需更正这些信息，请联系 HR。

**提示：** 请保持 **紧急联系人** 和 **紧急联系电话** 填写完整。这是 HR 在真正的紧急情况下首先查找的信息，而在入职时又很容易留空。

### 银行与税务信息（这些需要审批）

在 **我的资料** 卡片的右侧，你会看到你的 **银行与税务** 摘要，标记为 **更改需要审批**。它显示：

| 字段 | 你将看到的内容 |
| --- | --- |
| **银行** | 你的银行名称，例如 `Maybank` |
| **账户** | 为安全起见已遮蔽，例如 `•••• 1234` |
| **PCB 类别** | 你的税务类别——`单身`、`已婚，配偶不工作` 或 `已婚，配偶工作` |
| **受抚养子女** | 申报税务减免的子女人数 |

这些在此处为只读，因为它们关系到你的薪资和你的 PCB/MTD 税款预扣——任何更改在生效前都必须经管理员审批。要提交申请：

1. 在 **银行与税务** 摘要下方，点击 **申请变更** 以展开表单。
2. 只填写你想更改的字段：
   - **银行名称** 和 **账户号码** ——用于新的薪资账户。
   - **PCB 类别** ——保持在 **不更改**，或选择 `单身`、`已婚，配偶不工作` 或 `已婚，配偶工作`。
   - **受抚养子女** ——符合条件的子女人数。
3. 留空任何字段以保留其当前值（表单会提醒你：**留空以保留当前值**）。
4. 点击 **提交审批**。

随后你的申请会显示在表单下方的小列表中，并带有一个状态标签：`pending`（待处理）、`approved`（已批准）或 `rejected`（已拒绝）。在 `pending` 期间，你的实时信息保持不变。一旦管理员批准，新值会写入你的法定档案，摘要也会更新。

**常见陷阱**

- **更改银行账户是全有或全无。** 如果你填写了新的 **账户号码**，你也必须填写 **银行名称**（反之亦然）。只提交其中之一会被拒绝，并附上要求同时填写两者的提示——这可以防止把新账号保存到错误的银行名下。
- **空申请。** 如果你未输入任何内容就提交，你会收到 "Nothing to change"（无可更改）错误。请至少输入一个值。
- **审批人不是你的经理。** 银行和税务更改是 **管理员**（HR 管理员或超级管理员）的决定，而非经理的，因此如果你的直属经理无法处理它，不必感到意外。你无需额外操作——只需等待 `pending` 标签变为 `approved`。

**提示：** 请在下一次薪资发放运行 *之前* 处理好你的银行和 PCB 类别。更改只有在获批后才会影响你的薪资，因此一份在截止日期之后仍为 `pending` 的申请不会反映在当月的工资单中。

## 你的绩效考核

当你属于某个考核周期时，**员工自助服务** 下方会出现一个 **我的评价** 表格。每一行都会显示 **周期**、一段通俗易懂的 **状态**、**总体** 评分（发布后）以及右侧告诉你该做什么的链接。

状态文字是从你的视角书写的：

| 你将看到的状态 | 含义 | 你的操作链接 |
| --- | --- | --- |
| 自我评价 | 轮到你填写自我评价 | **开始自我评价** |
| 在你经理处 | 你已提交；你的经理正在撰写他们的评价 | *无需操作* |
| 等待发布 | 经理已完成，但尚未与你分享 | *无需操作* |
| 待确认 | 评价已发布——阅读并确认 | **确认** |
| 已确认 | 全部完成 | **查看** |

点击操作链接以打开评价页面（`/performance/review/...`）。顶部有一个 **返回员工自助服务** 链接，方便你轻松返回。

### 完成你的自我评价

1. 在 **我的评价** 中，点击相关周期上的 **开始自我评价**。
2. 在评价页面上，找到 **自我评价** 卡片。
3. 填写：
   - **你的评分** ——必填。从评分量表中选择一个值；每个选项都会显示其数字和标签（例如 `4 · 超出预期`）。
   - **评论** ——可选。用几行文字写下你的成果、挑战以及这段时期的情况。
   - **引用的目标** ——可选。记下你所对照反思的目标或任务。
4. 点击 **提交自我评价**。

提交后，状态会变为 **在你经理处**，你的自我评价会变为只读——你会看到你的评分和评论回显出来。下方的 **经理评价** 卡片会显示其在你经理完成之前仍处于待处理状态。

**注意：** 当评价在你经理处或仅在等待发布时，你不会看到经理的评分、评论或任何薪资建议。在评价正式 **发布** 之前，经理部分对你保持隐藏。

### 确认你经理的评价

一旦你的经理完成定稿且评价被 **发布**，**我的评价** 状态就会变为 **待确认**。

1. 在 **我的评价** 中，点击 **确认**（或打开评价并滚动到底部）。
2. 阅读 **经理评价** 卡片——你现在会看到 **经理评分**、**总体评分** 和任何 **评论**。**总体** 数字也会显示在你的 **我的评价** 表格中。
3. 在底部的 **确认** 卡片中，点击 **确认** 以表明你已看过并讨论过它。

确认会记录你已阅读该评价——这并不意味着你必须同意每一点；那正是与你经理对话的目的。确认后，状态会变为 **已确认**，该行的链接会变为 **查看**，因此你随时可以重新打开评价以供参考。

**提示：** 如果某一行显示 **等待发布** 或 **在你经理处** 并标注 *无需操作*，那么确实暂时没有你需要做的事——等你的经理完成后再回来查看。当出现 **确认** 链接时，你就会知道评价已就绪。

## 故障排除

- **员工自助服务显示我的账户未关联。** 如果你看到一条消息说你的账户未关联到员工档案，那是因为你的登录尚未连接到员工记录。只有在 HR 关联你的账户后，个人资料和评价功能才会出现——请联系 HR。
- **我看不到我的评价表格。** 它只在你在某个周期中至少有一份评价时才会显示。没有周期，就没有表格。
- **我的银行/税务更改仍显示旧值。** 请检查 **申请变更** 下方的申请列表。如果标签仍显示 `pending`，说明它在等待管理员处理；如果显示 `rejected`，请提交新申请（并仔细核对你是否同时填写了银行名称和账户号码）。
- **没有确认按钮。** 该评价尚未发布。请等待 **我的评价** 状态显示为 **待确认**。
