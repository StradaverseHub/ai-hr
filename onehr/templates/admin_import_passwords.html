How it works

Upload a file with two columns — Employee ID and Password. For every row whose Employee ID matches a user, that user's password is set to exactly the password you provide (header names are flexible / case-insensitive):

Employee IDPassword
X0004example-password-1
X0005example-password-2

People are matched by Employee ID; admin accounts are never changed. If any row has no match, no password, or a duplicate Employee ID, the whole file is rejected and nothing is changed — fix it and re-upload. Download the template (Excel) (its example rows are placeholders and match nobody — replace them with real Employee IDs).

Handle with care. This file contains plaintext passwords. OneHR never keeps them: as the file is read each password becomes its hash, and only the hashes wait for you to apply it (a day at most). Use strong, unique passwords and delete your copy of the file after import.
