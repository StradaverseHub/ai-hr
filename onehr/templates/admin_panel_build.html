How it works

    {% if cap %}
  • Nobody rates more than {{ cap }} people in a cycle, whatever the role.
    • {% else %}
  • There's no maximum on how many people one person rates: the super admin's choice on 360 Feedback › Settings › Rules. Whoever has the least to do is still picked first.
    • {% endif %}
  • Each person gets their line manager first,{% if prior_name %} then the raters they had on their {{ prior_name }} panel,{% endif %} then direct reports, then peers in the same business group, unit and department; the unit's other departments only when that isn't enough. Target {{ target }}; {{ min_valid }} is enough to be scored.
    • {% if cap %}
  • A manager with a team bigger than {{ cap }} rates {{ cap }} of them, those with the fewest other people to ask; colleagues rate the rest.
    • {% endif %}
  • Only confirmed employees get a panel. Anyone active may serve as an assessor.
  • Job grade H is rated by their line manager only.
  • Affects the active cycle only.

This page only ever adds. It never removes an assessor, never archives one, and never touches an assessment somebody has already submitted. To empty a panel, {% if nav_is_super %}use Clear panels, above{% else %}ask a super admin (Clear panels is theirs){% endif %}.
