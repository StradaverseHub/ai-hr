How it works

  • One row a person. Columns: {% for c in cols %}{{ c }}{{ ', ' if not loop.last }}{% endfor %}.
  • Route is KPI or Line manager. Appraiser employee ID is optional: blank means their line manager on OneHR. HOD employee ID is optional too: it is the person's HOD for Grade H only, and blank means their HOD on OneHR. Their HOD in the main review is never changed.
  • Second HOD employee ID and HOD split % are optional: fill them only when two HODs share the person. Both then calibrate them and their HOD band is the two bands weighted by the split. The split is the first HOD's share, 10 to 90 in steps of 10; blank with a second HOD means 50. A file without these columns never changes a second HOD set already; with them, a blank cell takes it away after you answer.
  • Supervisor name is the supervisor in the source file. It is kept as text for a person with no line manager; OneHR never makes one up.
  • Only people already in OneHR at grade H go on. A row marked Private company (Yes) is skipped and counted, not loaded.

Four steps. A row that cannot go in stops the file and every issue is listed. Then OneHR shows who goes on, you answer for anyone whose route or appraiser changes after they have started, and you apply that same file.
