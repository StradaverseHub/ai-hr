How it works

  • Upload a file with one Employee ID column — the subjects whose panels you want to clear.
  • Pending assessors (no feedback yet) are removed.
  • Submitted assessors are archived — their feedback is preserved and can be restored from the panel editor. Nothing is lost.
  • Affects the active cycle only.

Four steps, all or nothing. If any Employee ID is unknown, nothing is changed and every issue is listed so you can fix the file and choose it again. Then OneHR shows each panel, you answer for anyone whose raters have already given feedback, and you apply that same file.
